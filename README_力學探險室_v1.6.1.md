# 力學探險室 v1.6.1 — 例行檢查修正版

## 檢查範圍

- HTML 結構、JavaScript 語法與事件綁定
- 槓桿雙砝碼／受力量表切換、力計操作與一鍵平衡
- 定滑輪、動滑輪示意動畫／動態物理切換
- 暫停、續播、重新開始、參數變更重置
- 轉動慣量、張力、軸摩擦、靜摩擦情境
- 1440px 桌面、820px 平板、390px 與 320px 手機版面

## 本版修正

1. 動態物理模式的說明不再被舊文案覆蓋，並明確說明已計入可切換的滑輪轉動慣量與軸摩擦。
2. 實驗結束後位移預測會使用實際模擬位移，而非示意模式預定拉繩距離；可輸入負值預測下降。
3. 重新逐幀判定止擋接觸，避免離開擋板後仍沿用舊碰撞標記，影響張力顯示。
4. 懸空靜止且未接觸止擋時，顯示靜力平衡下的繩張力；到達止擋時保留拘束提示。
5. 調整動態狀態文字，避免已停止運動仍被描述成正在移動，並排除重複的端點提示。
6. 平板與窄螢幕物理數據卡改為兩欄，避免「實驗後揭曉」的文字被擠成數行。
7. 進階模式的滑輪位移參考線改用物理模擬的實際位移，並減少平板圖面頂部標籤擁擠。

## 使用方式

直接開啟 `index.html`，不需安裝套件；亦可直接放至 GitHub Pages。

## 物理模型限制

教學用簡化剛體模型：重力加速度固定為 10 N/kg，繩索無重、不可伸長且不打滑；簡化軸摩擦、速度阻尼及止擋反應，未模擬繩索彈性、材料變形、滑動接觸和真實輪軸細節。
