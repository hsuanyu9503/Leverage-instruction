# 力學探險室 v1.2｜動畫細節優化

適用對象：國小高年級、國中自然科學教學。純前端單一 HTML 網站，不需要註冊、安裝套件或串接後端服務。

## 快速開始

- 電腦或手機：直接使用瀏覽器開啟 `index.html`。
- GitHub Pages：將壓縮檔內的 `index.html` 上傳到儲存庫根目錄，再於 Settings → Pages 設定從主分支根目錄部署。
- 手機、平板與投影：版面自動調整，頂部的「投影模式」可隱藏教師設定欄。

## 實驗模式

1. **槓桿**：設定負載／施力砝碼質量、兩側位置、支點位置；可直接拖曳 SVG 上的砝碼或支點。動畫顯示傾斜或平衡，公式可顯示力臂、重力、力矩與淨力矩。
2. **定滑輪**：設定重物質量、向下施力、預計拉繩距離。理想情況下有效承重繩段為 1，向下拉繩距離與重物上升距離相同。
3. **動滑輪**：設定重物質量、向上施力、預計拉繩距離。理想情況下有效承重繩段為 2，拉繩距離為重物升高距離兩倍。

## v1.2 更新

- 調整槓桿旋轉的起步與停止節奏，避免一開始就迅速移動後立即減速。
- 定滑輪的輪輻與繩索標記沿捲繞方向旋轉／移動；動滑輪的輪子則依上升位移反方向轉動。
- 加入重物／滑輪原始位置的虛線殘影，以及拉繩與重物的位移參考線；實驗結果公開後才標出數值。
- 對定滑輪實施合理的畫面位移縮放，避免高拉繩距離時重物圖示碰撞輪子。
- 增加「慢速 0.6×／標準 1×／快速 2×」播放速度切換，以及播放期間的「暫停／繼續」。變更播放速度保留已完成的百分比進度。
- 播放期間仍可使用「重新預測」停止動畫並重置；改動實驗參數時，也會停止動畫、回到準備狀態。
- 預測選項與距離猜測在播放開始後鎖定，避免實驗答案揭曉後修改預測。
- 效能優化：每影格只更新 SVG 示意圖，不反覆重建說明區、數字卡與無障礙即時狀態訊息。
- 優化小螢幕的頁首按鈕排列和實驗 SVG 放大呈現。

## 課堂建議流程

1. 選擇「槓桿／定滑輪／動滑輪」，調整質量、支點、拉力等實驗條件。
2. 保持「探究模式：開」，選擇學生預測；可填入預測的上升距離。
3. 使用「慢速」開始實驗，可在關鍵畫面暫停、請學生說明觀察到的現象。
4. 動畫結束後比對模型結果，必要時切換「顯示力矩／顯示計算」提供國中的數值延伸。
5. 點選「重新預測」再次探究，或關閉探究模式改用「即時展示」。

## 模型與數學假設（重要）

- 重力加速度固定為 `g = 10 N/kg`。
- 忽略槓桿自重、滑輪和繩索的重量、軸承摩擦與其他能量損耗。
- 槓桿淨力矩以支點左右兩側產生的順時針／逆時針力矩合計；角度與轉動快慢為定性的視覺示意，**不是**求解角加速度的物理模擬。
- 滑輪動畫假設使用者能控制拉繩距離；拉力小於理想平衡拉力時不會向上移動。拉力大於平衡拉力時，真實自由運動會有加速度；此工具僅示範在理想化緩慢或受控操作中，力與繩長位移的關係。
- 為避免顯示區中的重物與滑輪重疊，SVG 中的位移使用同一模式內的視覺比例進行繪製；以資訊卡上的 **cm 數值** 作為正式量化結果。
- 使用者選擇系統層級「減少動態效果」時，動畫會直接跳到完成狀態。

## 已執行測試

- Chromium：桌面寬 1440 px、手機寬 390 px、窄螢幕 320 px；三種模式播放、暫停、繼續、重播、切換參數、顯示公式和投影模式。
- 槓桿滑鼠拖曳、播放中更改參數自動重置；無 JavaScript 執行錯誤。
- 已確認 320／390／1440 px 測試環境未出現整頁水平捲動。不同瀏覽器和裝置仍建議上線前實機試用。
