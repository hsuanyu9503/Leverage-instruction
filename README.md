# 力學探險室 v1.6.4｜第二輪素材避讓檢查

## 本輪修正

- **槓桿施力量表固定安全區**：不再跟隨上升的施力端下移，而是放在支點上方的保留空間，以虛線連結施力點，避免與槓桿、施力箭頭重疊。
- **量表直接拖曳仍可使用**：量表移位後，重新同步指標值與量表刻度的觸控座標。
- **滑輪的說明文字搬到圖外**：定滑輪固定位置、動滑輪兩段繩索承重及位移比例改由獨立的圖說區呈現，避免與繩索、箭頭、砝碼及滑輪交疊。
- **保留槓桿的獨立刻度尺**，以及原本雙砝碼、量表、探究與動態物理模式。

## 建議驗收操作

1. 槓桿切換到「量表施力模式」，負載設 20 kg、負載位置 25 cm、支點 100 cm、施力位置 190 cm；開始實驗觀察右側槓桿上升時的力計位置。
2. 量表中直接上下拖曳讀數，確認施力值改變且藍色箭頭同步。
3. 定滑輪與動滑輪各調到 20 kg、拉繩距離 150 cm，確認說明標籤不壓在圖像上。
4. 在 320px、390px、820px 和桌面寬度重測操作。

本版以素材避讓與可讀性為主，不修改物理運算核心。模型仍屬教學級簡化動態物理模擬。
