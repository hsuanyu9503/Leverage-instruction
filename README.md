# 力學探險室 v1.7.2

## 本版重點：天秤比例與操作優化

- 重新調整橫桿、中央立柱、底座、吊線與秤盤的比例，保留秤盤升降空間。
- 秤盤維持水平，吊線隨掛點上下移動，砝碼置於秤盤上方；砝碼體積仍依固定密度比例顯示。
- 秤盤整體可拖曳（不必只點中小圓點），直接改變左／右掛點位置。
- 刻度尺新增**橘色左掛點、藍色右掛點、黃色支點**三個可拖曳標記。使用鍵盤左右方向鍵可每次調整 5 cm；Home／End 可移至可用範圍端點。
- 保留雙砝碼、施力量計、定／動滑輪、探究模式、一鍵平衡及動態物理計算。

## 操作提示

1. 先選擇「槓桿原理」。
2. 直接拖曳秤盤，或拖曳刻度尺的彩色標記調整掛點與支點。
3. 切換「雙砝碼模式」／「量表施力模式」進行比較。
4. 可選擇是否顯示力矩；再按開始實驗播放動畫。

## 模型說明

為教學模型，採 `g=10 N/kg`，忽略或簡化部分實體天秤的秤盤自重、繩索伸縮、軸承接觸與材料形變。力矩運算與之前版本相同。極端掛點相近時仍可能出現實體元件無法同時佔用的示意限制。
