# 力學探險室 v1.6.2｜砝碼與刻度版面優化

## 本版修正

本版延續 v1.6.1 的槓桿、定滑輪、動滑輪與進階物理模擬功能，重點修正放大砝碼遮住刻度、標籤與圖例的問題。

1. **槓桿刻度尺獨立**：將 0–200 cm 刻度尺移到圖下方的獨立區塊，不與砝碼共用畫布，支點位置另以黃色指示線標示。
2. **力臂標示移至刻度區**：啟用「顯示力矩」後，負載力臂與另一側力臂以橘色、藍色標線及文字呈現，避開砝碼、槓桿與力量計。
3. **實驗畫面自動保留空間**：依砝碼尺寸、支點及施力位置估算最大轉角所需的高度；手機版在砝碼貼近左右邊緣時會放寬畫面，避免裁切。
4. **圖例不覆蓋教具**：把圖例改成實驗圖上方的獨立一列，避免遮蔽滑輪上方橫桿；拖曳提示則移到圖下方。
5. **滑輪重物標籤與間距**：依重物尺寸調整定滑輪的「重物」標籤位置，動滑輪重物較大時稍微提升初始圖像位置，避免貼近底部。
6. **固定密度的砝碼尺寸保留**：重量變化仍依質量的立方根縮放長、寬、高；未改動重力、力矩、張力、摩擦、轉動慣量等物理計算模型。

## 使用方式

- **直接開啟** `index.html` 即可使用。
- **部署 GitHub Pages**：將壓縮包內 `index.html` 上傳至儲存庫根目錄，依 GitHub Pages 設定發布。
- 槓桿模式可切換「雙砝碼／量表施力」；開啟「顯示力矩」後，刻度尺會額外標示兩段力臂。

## 本輪測試

- JavaScript 語法檢查：通過。
- Chromium 執行測試：1440、820、390、320 px，雙砝碼／量表切換、力矩顯示、一鍵平衡、三種實驗切換、進階物理設定，均未出現 JavaScript 執行錯誤或整頁水平溢出。
- 邊界情境：20 kg 砝碼、支點靠近 10 / 190 cm、位置靠近 0 / 200 cm，刻度尺與實驗畫面分離，手機版不裁掉大砝碼。

## 模型說明

本版是介面與繪圖配置修正版，不更改 v1.6.1 的動態物理運算假設，仍屬教學用簡化模型。
