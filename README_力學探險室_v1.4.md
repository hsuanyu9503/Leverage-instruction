# 力學探險室 v1.4

## 本次更新

1. **槓桿模式新增切換**：可在「雙砝碼模式」與「量表施力模式」之間切換。
2. **保留原本雙砝碼教學模式**：適合進行兩側重量比較與平衡判斷。
3. **量表施力模式保留**：適合進一步教施力大小、力臂與力矩。
4. **一鍵平衡會依模式切換邏輯**：
   - 雙砝碼模式：自動計算另一側需要的砝碼重量。
   - 量表施力模式：自動計算另一側需要的施力大小（N）。
5. **圖像微調**：
   - 量表放大且顏色更明顯。
   - 砝碼大小差異更清楚。
   - 手機版模式切換按鈕與標籤排版優化。

## 適用教學

- 國小：先用雙砝碼模式觀察哪邊會下降，再切到量表模式理解施力。
- 國中：搭配力矩、力臂、重力與施力做定量分析。

## 部署方式

- 直接開啟 `index.html` 即可使用。
- 若要部署到 GitHub Pages，可上傳部署包中的檔案到 repository 根目錄。
